# Game Chat Translator 0.1.1 prerelease

This usability update makes the desktop app easier to set up and operate:

- translations now appear directly in the main Status page instead of a separate window;
- a redesigned dark navigation rail replaces the cramped tab strip;
- the Status page shows OCR, calibration, profile, and monitoring readiness at a glance;
- model and profile pages now explain their real local state and next action;
- launching the app twice activates the existing window instead of racing the local database;
- the translator remains local-first, free, and offline during normal use.

The installer is unsigned. Windows may show a reputation warning. Verify the adjacent SHA-256 file before running it.

Model weights are downloaded separately after explicit user action and are not bundled. Real-game OCR quality still depends on correctly calibrating the chat region and on the selected game profile.
